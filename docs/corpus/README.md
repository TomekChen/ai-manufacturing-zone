# 知识库语料合规分层说明

公开知识库（WeKnora，门户问答与 PRD 接地共用）只收录「可商用合规」语料：

## 公开层（docs/corpus/urls.json，已入库 10 篇）
- 国家政策 6 篇：gov.cn 公文，著作权法第五条豁免
- 省级政策 1 篇 + 部委通知 1 篇：同上
- 开源文档 2 篇：WeKnora GitHub、Dify docs（Apache-2.0）

## 内部参考层（不入公开知识库）
- 知网论文 7 篇（清单见 docs/archive/知网检索式与下载清单.md）：2026-10-15 起从
  WeKnora 公开库移除，仅作团队内部参考。理由：期刊论文版权不属于本站，公开
  问答引用存在合规风险。删除前文档元数据备份在服务器
  backups/weknora_docs_pre-cnki-downgrade-20261015.json。
- 国标全文：在线阅览 ≠ 授权复制，不入库。

## 收录原则（新增语料先过这三条）
1. 授权等级可商用（公文豁免 / 开源许可证 / CC-BY / 自有内容）
2. 与知识库三场景相关（问答 RAG、PRD 行业接地、离线评测集）
3. 死链 / JS-SPA 空壳不收录
